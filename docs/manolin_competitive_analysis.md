| Capability | Manolin Detail |
|------------|----------------|
| Data scale | 265M+ smolts traced, 2,400 cages, 9.1B+ data points, 30+ years history |
| Model count | 19 new models (2025): 11 harvest-planning, 8 sea-lice clustering |
| Forecast range | 90-day cage-level biomass/quality/price forecasts |
| Accuracy claims | 85-97% accuracy on harvest planning models |
